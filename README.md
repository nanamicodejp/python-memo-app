# Python メモアプリ

Pythonで作成したターミナル型のメモアプリです。

## できること
- メモの表示
- メモの追加
- メモの削除
- メモの編集
- メモの検索
- 完了 / 未完了の切り替え
- 並び替え

## 使用技術
- python

## 実行方法
- python app.py

## 保存ファイル
- memo.txt

## 工夫した点
- 関数ごとに処理を分けて見やすくした
- 検索機能を追加した
- 完了 / 未完了の切り替えができるようにした
- 並び替え機能を追加した
